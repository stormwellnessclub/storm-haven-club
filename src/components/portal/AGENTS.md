- Every client screen (PT page, dashboard cards, bookings history) reads PT data only through `pt_my_portal()`/`pt_my_requests()`; clients have no direct read or write policies on PT appointments, passes, payments, installments, refunds, usage or requests, and cancel only via `cancel_pt_appointment`. Why: those rows carry staff-only notes columns.
- Client PT requests: options/times come only from `pt_client_request_options()`/`pt_client_request_times_all()` (every eligible trainer together, one-hour blocks from each trainer's window start; `pt_client_request_times()` is the single-trainer variant) (start times only, via the internal `pt_client_slot_is_open` + `pt_check_slot_core`, which add class conflicts), requests are created only by `pt_request_create` and read via `pt_my_requests()` (no client policies on training_requests); the portal keeps the approved Overview → Request Session → Requests + Upcoming layout and requests never create appointments. Why: request rows hold staff notes and clients must never see trainer calendars.
- Client PT screens (`useMyPTPortal`/`useMyPTRequests`) refresh on app focus, on open and every 30s while visible. Why: the app-wide query default disables focus refetch, so staff confirmations stayed "Awaiting confirmation" until clients restarted the app.
- Clients cancel/change their own pending PT requests only through `pt_request_client_cancel`/`pt_request_client_change` (re-checks the slot via `pt_client_slot_is_open`); staff schedules show pending requests as dashed holds under the trainer via staff-only `pt_schedule_pending_requests`. Why: request rows hold staff notes, and trainers must not be overbooked while a request waits.
- PT waitlist: `pt_client_request_times_all` tags hours as open/full/waitlisted (full = taken by another client via `pt_client_slot_is_full`, never blocks/time off); clients join/leave only through `pt_waitlist_join`/`pt_waitlist_leave` and read `pt_my_waitlist()`; "Change time" hides full hours. Staff calendar tags come from `pt_schedule_waitlist`. Why: clients must never see who holds a time, and joining never books or charges.
